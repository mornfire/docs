模组添加教程

本教程说明如何向 MFoC 客户端的模组包中添加额外模组。

注意：添加模组属于玩家自愿行为，不保证与服务器完全兼容。如因添加模组导致客户端崩溃或无法连接服务器，需自行解决。服务器仅提供操作指导，不承担技术兜底责任。

前置条件

  • 已安装 MFoC 整合包客户端
  • 了解模组文件的基本格式（.jar）
  • 具备基本的文件管理操作能力

操作步骤

第一步：确认模组来源

从可信渠道下载模组文件：

  • QQ 群文件
  • PCL，HMCL的下载分区
  • Modrinth（https://modrinth.com）
  • CurseForge（https://www.curseforge.com/minecraft）
  • 模组作者的官方 GitHub 仓库

第二步：确认模组版本

服务器版本为 1.21.1 NeoForge。添加的模组必须：

  • 支持 Minecraft 1.21.1
  • 支持 NeoForge 加载器

第三步：放入模组文件夹

  1. 打开 MFoC 客户端所在的文件夹
  2. 进入 .minecraft 目录，寻找到服务器的版本文件夹
  3. 找到 mods 文件夹
  4. 将下载的 .jar 文件放入 mods 文件夹

注意：请勿放置 -client 后缀的专用客户端模组，此类模组可能导致服务器端无法正常加载，建议确认是否为通用客户端端模组或仅在客户端生效的辅助模组。

第四步：启动测试

正常启动客户端。如能成功进入游戏主菜单，且能连接服务器，则说明添加的模组与当前环境兼容。

常见问题

问题 可能原因 建议
客户端启动崩溃 模组版本不兼容、模组依赖缺失、与其他模组冲突 检查模组是否支持 1.21.1 NeoForge，部分模组需要额外的前置模组
连接服务器失败 模组与服务端不匹配 添加的模组仅在客户端侧不修改协议时不影响连接，但若模组改动通信协议会报错，则需移除该模组
游戏内某些功能异常 添加的模组影响了服务器规则或机制 移除该模组，恢复到原有模组包状态

添加模组的原则

  • 一次只添加一个模组，便于排查问题
  • 添加前备份 mods 文件夹
  • 如无法连接服务器，尝试移除新添加的模组
  • 添加模组后如出现客户端崩溃，请自行定位问题
